Konjo Bet — Advert folder
========================

Drop your banner images here (JPG, PNG, or WebP).

Then list each filename in manifest.json:

{
  "slides": [
    "your-banner-1.jpg",
    "your-banner-2.png"
  ]
}

Slides appear in order as a carousel on the sportsbook home page.
Recommended size: 1200 x 280 px (wide banner).
