=====================================================
  Lucky Bingo - Called Numbers Voice Audio Files
=====================================================

Upload your audio files for the 75 bingo calls into this folder:
assets/audio/

Supported file formats:
- .mp3 (recommended)
- .wav
- .m4a
- .ogg

Supported naming conventions (choose whichever you prefer):

Option A: Letter + Number (recommended, e.g. B5, I22, N35, G58, O72)
  B1.mp3, B2.mp3, ..., B15.mp3
  I16.mp3, I17.mp3, ..., I30.mp3
  N31.mp3, N32.mp3, ..., N45.mp3
  G46.mp3, G47.mp3, ..., G60.mp3
  O61.mp3, O62.mp3, ..., O75.mp3

Option B: Number only (e.g. 1, 2, ..., 75)
  1.mp3, 2.mp3, 3.mp3, ..., 75.mp3

Option C: Hyphenated (e.g. B-1, I-22)
  B-1.mp3, B-2.mp3, ..., O-75.mp3

The game automatically detects and plays the audio for each number as soon as it is drawn.
If an audio file is not yet uploaded, the game continues seamlessly without any errors.
